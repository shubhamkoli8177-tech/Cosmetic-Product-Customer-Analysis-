# Cosmetic-Product-Customer-Analysis-
Cosmetic Product &amp; Customer Analysis Dashboard using Power BI. Analyzing product performance, customer insights, sales trends and revenue. 
This Power BI dashboard project provides insights into cosmetic sales, products, customers, advertising, regions, and orders. It includes seven pages featuring executive KPIs, sales trends, category and brand analysis, top products, campaign performance, customer segments, payment methods, state-wise revenue, and detailed order and delivery reports with interactive filters for analysis.
